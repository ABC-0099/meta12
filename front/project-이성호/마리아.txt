BEGIN 다음 DECLARE

counter (카운터): * 변수의 이름
INT (인티저): *데이터 타입(형태)
DEFAULT 1 (디폴트 1): * 초깃값

WHILE counter <= 50 DO
WHILE (와일): * "~하는 동안에"라는 뜻입니다. 뒤에 나오는 조건이 **참(True)**인 동안에는 절대 멈추지 말고 계속 돌아가라는 신호입니다.

counter <= 50 (조건식): * 현재 counter라는 바구니에 든 숫자가 50 이하인지 검사합니다.

만약 51이 되는 순간? 이 조건은 **거짓(False)**이 되어 반복문을 즉시 탈출하게 됩니다.

DO (두): * "자, 조건이 맞으니까 이제 아래 일들을 실행해(Do)!"라는 뜻입니다.

===============================================================================================
SELECT CONCAT('현재 숫자 : ', counter);
SELECT (셀렉트): 화면에 보여줌
CONCAT (콘캣): 'Concatenate'의 약자로, 여러 개의 문자열이나 변수를 하나로 합쳐주는 집선기 같은 함수입니다.

괄호 안에 쉼표(,)로 구분해서 넣으면 순서대로 이어 붙여줍니다.

'현재 숫자 : ' (문자열):

작은따옴표(')로 감싸진 부분은 있는 그대로 출력되는 고정된 글자입니다.

counter (변수):

아까 DECLARE로 만든 변수입니다. 루프가 돌 때마다 1, 2, 3...으로 변하는 실제 숫자가 이 자리에 들어갑니다.

SET counter = counter +1;
SET (셋):
"값을 설정하겠다!" 또는 "바구니의 내용물을 바꾸겠다!"라고 선언하는 명령어입니다.
 DECLARE가 바구니를 처음에 만드는 것이라면, SET은 그 안에 든 것을 교체하는 것입니다.

counter = (왼쪽):
이건 "수학적으로 같다"는 뜻이 아니라, 
**"오른쪽 계산 결과를 이 바구니에 다시 집어넣어라"**라는 대입(Assignment)의 의미입니다.

counter + 1 (오른쪽):
현재 바구니에 들어있는 값(예: 1)에 1을 더합니다.
결과값은 2가 되고, 이 2가 다시 왼쪽의 counter 바구니로 쏙 들어갑니다.

create or replace procedure process_tax()
begin
-- 변수 선언
DECLARE done INT default false;
DECLARE v_name varchar(50);
DECLARE v_salary decimal(10,2);
DECLARE v_tax DECIMAL(10,2);

-- 커서 선언 : 직원 이름과 급여 조회
DECLARE emp_cursor cursor for
select emp_name, salary from employees;

-- 더이상 데이터가 없을때 done = true 설정
DECLARE CONTINUE HANDLER FOR NOT FOUND SET done = TRUE;

OPEN emp_cursor;

read_loop:LOOP
FETCH emp_cursor INTO v_name, v_salary;

-- 데이터가 없음 루프 종료
IF done THEN
LEAVE read_loop;
END IF;

-- 급여가 NULL 인 경우 세금 0 처리
IF v_salary IS NULL THEN
set v_tax = 0;
ELSE
set v_tax = v_salary * 0.1;
END IF;

-- 세금 정보 출력
select concat(v_name, '의 세금은 ', v_tax, ' 원 입니다.') AS tax_info;
END LOOP read_loop;

close emp_cursor;
END //

DELIMITER ;
